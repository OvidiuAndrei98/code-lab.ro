# Typography-led studio composition

Create original studio websites using the visual relationships in the user's `cosmo.mp4`. Read [the recording evidence](references/recording-study.md) before adapting a specific relationship. This is a local design synthesis, not the source website's code or an official Cosmos skill.

## Establish an identity, then give the work room

The recording's most distinctive first-screen decision is a very large, narrow wordmark across a restrained light canvas. Navigation and practical context stay small and aligned above it. The imagery that follows is a separate strong field, with enough contrast to hold its own against the lettering.

Use this relationship only when the actual brand name and available typeface support it. Do not horizontally crush a regular font or make useful body text condensed. Preserve existing brand assets when fidelity is requested. A large wordmark is not permission to copy the source's logo, exact letterforms or giant footer identity.

Use a small set of type roles, clear shared margins and quiet interface surfaces. The projects, not a collection of decorative controls, supply the color and variety. Keep body text readable, especially when reducing the desktop composition for a phone.

## Change density according to the content

The work area has a centered introduction followed by dominant project media. The studio explanation uses paired surfaces with different jobs: one explains the team, the other demonstrates identity or a visual system. Services are a denser list, with descriptions and small supporting images rather than identical feature cards.

These are independent relationships, not a required page inventory. Select the ones supported by the business and its evidence. Do not automatically append an awards strip, metrics, an FAQ, clocks, a booking widget or a cookie banner because they appear in the recording. Do not fabricate awards, locations, people, counts or reviews.

Keep a meaningful title, scope and destination associated with every work sample. Project imagery should show one coherent project. Keep concept work distinguishable from actual commissioned work.

## Respect the user's design constraints

For this user, omit decorative stars and their substitutes, numbered section overlines and the conventional oversized closing CTA. The supplied recording contains decorative symbols and a giant footer wordmark; neither overrides those explicit preferences. Preserve a 2D implementation unless subsequently requested otherwise.

For the overlapping work motion, use `stacked-project-scroll` when available, or implement the same relationship within the existing scroll stack. Do not add global smooth scrolling unless requested or already established. Treat motion as an enhancement to a useful static composition.

Check the hero, a complete work sample, an expanded service state if present, the footer and a narrow phone rendering together. Test focus, normal navigation and reduced motion. Report the composition and interactions actually inspected.
